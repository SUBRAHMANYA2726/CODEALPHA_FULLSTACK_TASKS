# CodeAlpha Fullstack Internship Tasks

Welcome to the main repository for my CodeAlpha Fullstack Internship tasks! This repository consolidates all the projects developed during the internship into a single, unified workspace while preserving their independent structures, functionalities, and complete commit histories.

## 🚀 Internship Overview

During the CodeAlpha Fullstack Internship, I developed three comprehensive, modern web applications. The goal was to build scalable, full-stack systems with interactive UIs, secure authentication, and robust backend architectures.

## 💻 Project List

### 1. [E-Commerce Store](./CodeAlpha_Ecommerce_Store)
A modern full-stack e-commerce web application featuring secure user authentication, product browsing, a shopping cart, a wishlist, order management, an admin dashboard, and a responsive UI for seamless online shopping.

### 2. [Project Management Tool](./CodeAlpha_Project_Management_Tool)
A full-stack project management application with Kanban boards, task management, project collaboration, comments, due dates, priorities, and secure authentication.

### 3. [Social Media Platform](./CodeAlpha_Social_Media_Platform)
An interactive social media platform featuring user authentication, user profiles, real-time posts, comments, likes, a follow system, and a modern, responsive user interface.

## 🛠️ Technologies Used

Across these three projects, the following modern technologies were utilized:
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion
- **Backend & Database**: Node.js, Express.js, MongoDB, Firebase (Authentication, Firestore, Storage)
- **Real-Time Communication**: Socket.io
- **State Management & Data Fetching**: React Query, React Context API
